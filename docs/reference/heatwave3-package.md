# heatwave3: Detect Heatwaves and Cold-Spells in Gridded Data

Detect marine heatwaves (MHWs) and cold-spells (MCS) directly on gridded
'NetCDF' data using the definition of Hobday et al. (2016)
[doi:10.1016/j.pocean.2015.12.014](https://doi.org/10.1016/j.pocean.2015.12.014)
and the categories of Hobday et al. (2018)
[doi:10.5670/oceanog.2018.205](https://doi.org/10.5670/oceanog.2018.205)
. Implements climatology calculation, event detection, exceedance
analysis, event categorisation, blob detection, and visualisation. All
core algorithms are written in multi-threaded C++ for high performance
on large datasets.
