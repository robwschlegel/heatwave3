# heatwave3: Detect Heatwaves and Cold-Spells in Gridded Data

Detect marine heatwaves (MHWs) and cold-spells directly on gridded
NetCDF data using the Hobday et al. (2016, 2018) definition. Implements
climatology calculation, event detection, exceedance analysis, event
categorisation, blob detection, and visualisation. All core algorithms
are written in C++ with OpenMP parallelism for high performance on large
datasets.
