# Package index

<div class="section level2">

## Core workflows

</div>

<div class="section level2">

-   `detect3()` : All-in-one marine heatwave detection for gridded data
-   `ts2clm3()` : Compute climatology for gridded NetCDF data
-   `detect_event3()` : Detect marine heatwave events in gridded data
-   `category3()` : Convenience wrapper for marine heatwave event
    categories
-   `category_daily3()` : Daily marine heatwave / cold-spell categories
    for a date window
-   `exceedance3()` : Static threshold exceedance detection for gridded
    data
-   `block_average3()` : Block average of event metrics by year and
    pixel
-   `detect_blob3()` : Detect spatially connected marine heatwave blobs

</div>

<div class="section level2">

## Visualisation

</div>

<div class="section level2">

-   `event_line3()` : Plot a per-pixel MHW time series from NetCDF
    output
-   `plot_metric3()` : Spatial map of event metrics
-   `geom_flame3()` : Flame geom for MHW visualisation
-   `geom_lolli3()` : Lollipop geom for event metric visualisation

</div>

<div class="section level2">

## Export and threading

</div>

<div class="section level2">

-   `hw3_export()` : Read or export a heatwave3 NetCDF product
-   `getHW3threads()` `setHW3threads()` : Get or set the number of
    threads used by heatwave3

</div>
